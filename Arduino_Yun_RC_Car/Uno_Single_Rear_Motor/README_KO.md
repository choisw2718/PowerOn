# Arduino Uno 단일 중앙 후륜 모터 제어

이 폴더는 기존 양쪽 후륜 모터/엔코더 버전을 수정하지 않고 별도로 만든 독립 버전이다.

- 제어 보드: Arduino Uno R3
- 구동계: 중앙의 12 V DC 모터 1개 + 동력이 연결되지 않은 베어링 바퀴 2개
- 조향계: 앞바퀴 2개와 기존 조향 서보 2개 유지
- 통신: 노트북과 Uno 사이의 USB Serial, 115200 baud
- 제어 방식: 엔코더/PID 없는 open-loop PWM 전압 명령
- 사용하지 않는 기능: Bluetooth, Wi-Fi, ESP32, 엔코더, 속도 피드백, PID

## 파일

| 파일 | 역할 |
|---|---|
| `Uno_Single_Rear_Motor.ino` | Uno 펌웨어 |
| `serial_control.py` | 노트북에서 명령을 보내는 대화형 Python 도구 |
| `requirements.txt` | 노트북 도구의 `pyserial` 의존성 |

Arduino IDE의 스케치 폴더 규칙에 맞게 폴더와 `.ino` 파일 이름을 동일하게 두었다.

## 배선

기존 드라이버의 **채널 A(기존 왼쪽 모터 채널)**만 중앙 후륜 모터에 사용한다. 채널 B의 모터 출력에는 아무것도 연결하지 않으며, 펌웨어도 채널 B의 `ENABLE`, `PWM`, `IN1`, `IN2`를 모두 안전한 비활성 상태로 고정한다.

| 기능 | Uno 핀 | 연결 대상 |
|---|---:|---|
| 중앙 후륜 모터 PWM | D9 | 드라이버 채널 A PWM |
| 중앙 후륜 모터 방향 1 | D2 | 드라이버 채널 A IN1 |
| 중앙 후륜 모터 방향 2 | D4 | 드라이버 채널 A IN2 |
| 중앙 후륜 모터 활성화 | D3 | 드라이버 채널 A ENABLE |
| 왼쪽 서보 신호 | D5 | 기존 왼쪽 서보 채널 |
| 오른쪽 서보 신호 | D6 | 기존 오른쪽 서보 채널 |
| USB Serial | D0/D1 내부 연결 | Uno USB 포트만 사용 |

드라이버 ENABLE은 기존 사양대로 **low-active**다. 정지 시 펌웨어는 `ENABLE=HIGH`, `PWM=LOW`, `IN1=LOW`, `IN2=LOW`로 만든다. 방향이 바뀌면 먼저 출력을 끄고 50 ms 후 반대 방향을 구동한다.

## 전원 연결에서 꼭 지킬 점

1. 12 V 외부 전원의 `+`를 모터 드라이버 `MOTOR VCC`에 연결한다.
2. 12 V 외부 전원의 `-`, 모터 드라이버 로직 GND, Arduino GND, 서보 전원 GND를 공통으로 연결한다.
3. Arduino Uno는 노트북 USB로 전원을 공급한다. **12 V를 Uno 5 V 핀이나 GPIO에 연결하지 않는다.**
4. 서보 2개는 Uno 5 V 핀 대신 충분한 전류 용량의 별도 4.8~6.0 V 전원을 권장한다.
5. 모터 드라이버 로직 전원은 보드 사양에 맞는 안정화된 전원을 사용한다.
6. 모터 정지 전류가 드라이버의 허용 전류를 넘지 않는지 확인하고 퓨즈, 비상 정지 수단, 방열을 준비한다.

이 코드는 `VOLTAGE 6`을 약 50% PWM으로 바꾼다. 따라서 이상적인 평균 인가 전압 명령은 대략 `12 V × 50% = 6 V`다. 그러나 L298N 계열 드라이버의 전압 강하, 전원 상태, 모터 부하 때문에 실제 단자 평균 전압은 이 값보다 낮고 달라질 수 있다. 엔코더나 전압 피드백이 없으므로 실제 속도 또는 실제 단자 전압을 일정하게 유지하는 폐루프 제어는 아니다.

## Arduino 업로드

Arduino IDE에서 `Uno_Single_Rear_Motor.ino`를 열고 다음을 선택한다.

- Board: `Arduino Uno`
- Port: 연결된 Uno의 COM 포트

컴파일 후 업로드한다. 이 스케치는 추가 Arduino 라이브러리를 사용하지 않는다.

## Serial Monitor로 최초 시험

처음에는 차체를 받쳐 **구동 바퀴가 바닥에서 떨어진 상태**로 시험한다.

1. 모터용 12 V 전원을 끄고 USB만 연결한다.
2. Serial Monitor를 `115200 baud`, 줄바꿈 `Newline`으로 설정한다.
3. `STATUS`를 보내 모터가 `enabled=0`인지 확인한다.
4. `STEER 5`, `STEER -5`, `CENTER`로 앞바퀴 조향을 확인한다.
5. `STOP`을 보낸 뒤 모터용 12 V 전원을 켠다.
6. 구동 바퀴가 확실히 떠 있는지 다시 확인하고 `VOLTAGE 7.0`으로 실측 최소 기동 전압부터 짧게 시험한다.
7. 즉시 `STOP`으로 정지되는지 확인한다.
8. `VOLTAGE -7.0`으로 반대 방향을 짧게 시험하고 다시 `STOP`한다.
9. 회전 방향, 전류, 드라이버 온도를 확인하면서 전압 명령을 조금씩 높인다.

모터 구동 중 1.5초 동안 새 모터 명령이나 `KEEPALIVE`가 없으면 자동으로 정지한다. Serial Monitor 수동 시험에서는 명령 후 1.5초 뒤 멈추는 것이 정상이다.

## Serial 명령

각 명령 끝에는 newline을 붙인다. 대소문자는 구분하지 않는다.

| 명령 | 설명 |
|---|---|
| `VOLTAGE 6.0` | 정방향 nominal 6 V 명령, 즉 50% PWM |
| `VOLTAGE -3.0` | 역방향 nominal 3 V 명령, 즉 -25% PWM |
| `MOTOR 20` | 정방향 20% PWM |
| `MOTOR -20` | 역방향 20% PWM |
| `STOP` | 모터 즉시 정지, 조향 유지 |
| `STEER 10` | 차체 중심 기준 왼쪽 10도 조향 |
| `STEER -10` | 차체 중심 기준 오른쪽 10도 조향 |
| `CENTER` | 조향 중앙, 모터 상태 유지 |
| `IDLE` | 모터 정지 후 조향 중앙 |
| `STATUS` | 현재 명령/출력/서보/timeout 표시 |
| `TIMEOUT 1500` | 모터 watchdog 시간을 ms 단위로 설정 |
| `HELP` | 명령 도움말 표시 |

`VOLTAGE`는 -12.0~+12.0 V, `MOTOR`는 -100~+100%로 제한된다. 양수/음수는 방향을 뜻한다. 모터가 실제 차량 전진과 반대로 돌면 전원을 끈 뒤 모터 단자 두 선을 서로 바꾸거나, 스케치의 `kForwardIn1High` 값을 바꾼다.

## 노트북 Python 도구

Python 3이 설치된 노트북에서 이 폴더로 이동한 뒤 실행한다.

```powershell
py -m pip install -r requirements.txt
py serial_control.py --list
py serial_control.py COM5
```

실행 후에는 Enter를 누르지 않고 다음 키로 바로 조작한다.

| 키 | 동작 |
|---|---|
| `W` | 정지 상태에서는 +7.0 V로 시작, 이후 +0.5 V씩 증가 |
| `S` | 정지 상태에서는 -7.0 V로 시작, 이후 -0.5 V씩 증가 |
| `A` | 왼쪽 조향 2도 증가 |
| `D` | 오른쪽 조향 2도 증가 |
| `Space` 또는 `X` | 모터 즉시 정지, 조향 유지 |
| `C` | 조향 중앙, 모터 상태 유지 |
| `I` | 모터 정지 및 조향 중앙 |
| `R` | 현재 상태 요청 |
| `H` 또는 `?` | 키 도움말 표시 |
| `Q` 또는 `Esc` | `IDLE` 전송 후 안전 종료 |

실측 결과 -6.5~+6.5 V 구간에서는 모터가 기동하지 않으므로 키보드 제어는 이 구간을 명령하지 않는다. 정지 상태에서 `W`를 처음 누르면 `VOLTAGE 7.0`, `S`를 처음 누르면 `VOLTAGE -7.0`을 보낸다. 같은 키를 계속 누르면 7.5, 8.0 V처럼 0.5 V씩 증가한다.

반대 방향으로 전환할 때는 반드시 0 V를 거친다. 예를 들어 +7.5 V에서 `S`를 누르면 `+7.0 V → 0 V → -7.0 V` 순서로 바뀌며, 펌웨어도 방향 전환 전에 출력을 끄고 50 ms 동안 기다린다. `Space` 또는 `X`는 현재 전압과 관계없이 즉시 0 V로 정지한다.

키를 누르고 있으면 운영체제의 키 반복 속도로 명령이 계속 증가하므로 최초 시험에서는 구동 바퀴를 띄운 뒤 한 번씩 짧게 누른다. 키보드 조향은 기구 여유를 위해 -30~+30도로 제한되며, 펌웨어의 최종 안전 제한도 추가로 적용된다.

도구는 모터 명령이 0이 아닐 때 0.5초마다 `KEEPALIVE`를 보낸다. 도구가 종료되거나 USB 연결이 끊기면 keepalive가 사라져 Uno watchdog이 모터를 멈춘다. `Q`, `Esc`, Ctrl+C 또는 정상 종료 시에는 먼저 `IDLE`을 보내 모터를 정지하고 조향을 중앙으로 돌린다.
