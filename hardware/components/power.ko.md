# 차량 전원

| 전원 분기 | 현재 상태 | 확인 필요 |
| --- | --- | --- |
| 모터·L298N | 외부 12 V 벤치 공급 기록 | 차량 배터리·모듈 정격, 부하 시 전압 강하와 전류 |
| L298N 로직 | 외부 5 V에서 LED 켜짐 기록 | 사용 중인 모듈의 레귤레이터와 점퍼 구성 |
| 서보 2개 | 별도 안정화 전원 사용 계획, 기존 문서 기준 5 V | 공급원 모델, 출력 용량과 조향 중 전압 |
| Nano | USB 전원 사용 확인 | 차량 탑재 시 공급 방식 |
| Pi·라이다 | 벤치에서 Pi USB-C와 라이다 USB 연결 사용 | 탑재 전원과 고정 방식 |
| SHARP IR 센서 | 미장착 | 설치 후 센서 전원과 Nano ADC 입력 범위 확인 |

차량 배터리 모델·용량·보호 구성, 분기별 DC-DC 모델과 차단 방식은 미확인입니다. 제어의 전압 환산 기준은 [공용 프로필](../control_profile.json)에 기록합니다.
