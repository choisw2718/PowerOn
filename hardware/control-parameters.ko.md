# 차량 제어 파라미터

실행 기본값은 [control_profile.json](control_profile.json)에서 읽습니다. 아래 표의 **임시**와 **도면 추정** 항목은 실측으로 교체할 값입니다.

## 차체와 회전 반경

| 항목 | 현재 값 | 근거·측정 |
| --- | --- | --- |
| 차체 설계 기준 | 폭 150 mm × 길이 200 mm | body-3.5 스케치·B-rep 확인. 바퀴와 범퍼 돌출은 별도 |
| 후륜 트레드·좌우 유효 둘레·해상도 | 가상 기본 145 mm · 각 188.5 mm · 각 360 카운트/회전 | 실측 전 가정. 보정된 `dual_rear` 값이 가상 기본값에 우선 |
| 축간거리 | 133.24 mm | 도면 추정. 앞 조향축 선과 뒷차축 중심 간 거리 실측 필요 |
| 앞 조향 회전축 간격 | 121.20 mm | 도면 추정. 서보 좌우 회전축 사이 실측 필요 |
| 차량 폭·전후 길이 | 폭 230 mm, 라이다 중심부터 앞·뒤 각각 150 mm | 임시. 바퀴와 돌출부를 포함해 측정 |
| 라이다 기준 위치·전방각·거리 보정 | 뒷차축보다 앞 66.62 mm, 0°, 0 mm | 임시. 센서 고정 후 실측 필요 |
| 펌웨어 내부 바퀴 각도 제한 | −45°~+55° | 설정값. 각 앞바퀴의 안전 가동 각도 실측 필요 |
| 펌웨어 중심 조향각 범위 | 오른쪽 약 −34.50°, 왼쪽 약 +39.99° | 도면과 서보 펄스 범위에서 계산. 실물 한계 실측 필요 |
| 수동·라이다 중심각 상한 | 수동 ±30°, 라이다 ±28° | 명령 상한. 플러스는 좌회전 |
| 가상 모델·미리보기 최소 회전 반경 | 0.25 m | 임시. 뒷차축 중심이 그리는 원의 좌우 반경을 각각 측정 |
| ±28°에서의 계획기 반경 하한 | 약 0.251 m | 축간거리 ÷ tan(28°). 명령 각도 기준 계산값 |

회전 반경은 뒷차축 중앙의 궤적을 기준으로 합니다. 측정할 때는 차량을 저속으로 돌려 일정한 원을 만든 뒤 좌회전과 우회전의 반지름을 따로 기록합니다. 라이다 CLI에서 하나의 `--min-turn-radius`로 표현할 때는 두 실측값 중 큰 값을 사용합니다. 차체 바깥 궤적의 여유는 차폭·앞뒤 길이와 함께 계산합니다.

## 코드 반영

트랙 시뮬레이터는 차체 치수, 최소 회전 반경, 속도·감속과 가상 스캔 기본값을 사용합니다. 라이다 미리보기와 경로 계획은 같은 차체·동역학 기준을 사용합니다. 실차 `--drive`는 기존 절차대로 장착 위치·차폭·정지 거리·회전 반경 등의 측정값을 명시해야 합니다. [라이다 실차 주행 인자](../lidar/autopilot/guide.ko.md#4-pi에서-주행-준비)

Nano는 공용 프로필에서 생성한 헤더의 치수, 서보 값, 라이다 명령 상한과 IR 장착 상태를 사용합니다. 프로필 변경 후 저장소 루트에서 `python -m hardware.generate_firmware_profile`을 실행하고 스케치를 다시 빌드합니다.
