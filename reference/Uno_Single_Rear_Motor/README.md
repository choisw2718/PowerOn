# 기존 Arduino Uno 단일 후륜 모터 (참고용)

문서 기준일: **2026-09-30 (한국 시간)**. 메인 폴더는 **`C:\Users\user\Arduino\Nano_33_IoT`**이며 현재 개발 대상은 [Nano 33 IoT의 R 채널·Wi-Fi 제어](../../README.md)입니다. 전체 현황과 필요한 정보는 [개발 현황 문서](../../DEVELOPMENT.md)에 있습니다. 이 문서는 보존된 **Uno L 채널·USB 시리얼 버전**을 설명합니다.

이 폴더 코드의 대상은 **Uno R3 (ATmega328P, 16 MHz)**입니다. 앞바퀴 2개를 Hitec HS-311 서보 2개로 조향하고, 중앙 후륜 DC 모터 1개를 기존 **MAI-2MT-DC V3.0 드라이버의 L 채널**로 구동하도록 작성됐습니다. 실물 하네스가 L 채널에 연결됐는지는 확인해야 합니다. 좌우 후륜 독립 구동과 엔코더/PID는 사용하지 않습니다. [Nano 33 IoT 전환 배선안](../../WIRING.ko.md)은 **R 채널**이므로 아래 Uno 핀맵과 구분합니다.

## 코드와 실행

| 파일 | 용도 |
|---|---|
| `Uno_Single_Rear_Motor.ino` | Uno 단일 모터·두 서보 제어, USB 시리얼 명령 수신 |
| `serial_control.py` | 노트북 USB 시리얼 조종 |
| `requirements.txt` | USB 조종기의 `pyserial` 의존성 |

Arduino IDE에서 `Uno_Single_Rear_Motor.ino`를 열고 **Arduino Uno**를 선택해 업로드합니다.

노트북 조종기는 이 폴더에서 실행합니다.

```powershell
py -m pip install -r requirements.txt
py serial_control.py --list
py serial_control.py COM5
```

`W/S`는 전진·후진 명령을 7 V에서 시작해 0.5 V씩 조절하고, `A/D`는 좌우 조향, `C`는 조향 중앙, `X`/Space는 모터 정지, `I`는 모터 정지와 조향 중앙, `R`은 상태 조회, `Q`/Esc는 `IDLE` 전송 후 종료입니다. 조종기의 조향 범위는 -30°~+30°입니다.

## 보존된 Uno 코드의 배선 기준

| 기능 | Uno 핀 | 연결 |
|---|---|---|
| 후륜 모터 PWM | D9 | 드라이버 **5번 L_PWM** |
| 후륜 모터 방향 | D2 / D4 | **1번 L_IN1 / 2번 L_IN2** |
| 후륜 모터 ENABLE | D3 | **3번 L_ENABLE**, **LOW 활성** |
| 조향 서보 신호 | D5 / D6 | 기존 채널 L / R |
| USB Serial | D0 / D1 | Uno USB 연결에 사용 |
| 비사용 | A0 / A1 | 연결하지 않음 |
| 미사용 R 채널 | D10 / D7 / D8 / D11 | R_PWM LOW / R_IN1 LOW / R_IN2 LOW / R_ENABLE HIGH |

R 채널의 모터 출력은 비워 둡니다. 정지 시 L 채널은 `ENABLE=HIGH`, `PWM=LOW`, `IN1=LOW`, `IN2=LOW`입니다. 방향을 바꿀 때 먼저 출력을 끄고 50 ms 후 반대 방향으로 구동합니다. **Uno D3 직결만으로는 리셋 중 L_ENABLE이 HIGH라는 보장이 없으므로**, 모터 전원을 넣기 전 리셋·전원 순서의 정지 상태를 실물에서 확인해야 합니다. [Nano 전환 배선](../../WIRING.ko.md#5-d3-직접-연결과-정지-상태)도 D3 직결이므로 같은 한계가 있습니다.

코드는 신호 채널 L/R과 실제 좌우 바퀴가 교차된 것으로 가정합니다(`kServoChannelsCrossed = true`). 서보 중립 펄스 설정은 채널 L/R 각각 1398/1402 µs, 펄스 한계 설정은 948~1948/952~1952 µs이며 현재 기구에 안전한지는 재확인해야 합니다. 중심 조향각 기준 양수는 좌회전이며, 서보 방향과 기구 한계는 차체를 들어 올려 재확인하세요.

## 전원과 모터 기록

| 항목 | 보존된 Uno 문서·코드의 값 | 확인 상태 |
|---|---|---|
| 후륜 모터 | 중앙 DC 모터 1개, 모델명 미기록 | 실물 라벨·정격·정지 전류 확인 필요 |
| 모터 전원 | 외부 12 V, 스케치의 `kMotorSupplyVoltage=12.0` | 장착 모터에 맞는지 확인 필요 |
| 드라이버 | MAI-2MT-DC V3.0, 코드상 L 채널만 사용 | 실물 연결 확인 필요 |
| 드라이버 로직 전원 | 안정화된 4.5~6.0 V | 단자와 실물 보드 사양 확인 필요 |
| 두 서보 전원 | 별도 4.8~6.0 V, 충분한 전류 여유 | Uno 5 V 핀에서 직접 공급하지 않음 |
| 기동 보정 | `DRIVE` 명령은 0이 아닌 7 V 미만 값을 7 V로 보정 | 기존 실측 기록. 모터 교체 시 재측정 필요 |

매뉴얼상 모터 전원은 드라이버의 **별도 2핀 모터 전원 커넥터**에 넣습니다. 10핀 제어 커넥터의 **9번 VCC/10번 GND는 4.5~6.0 V 로직 전원**입니다. 매뉴얼의 모터 전원 허용 범위는 **5~46 V**, 채널당 한계는 **2 A**이지만, 이것은 장착 모터가 12 V/2 A에 맞는다는 증거가 아닙니다. 모터 라벨과 기동/정지 전류를 확인해야 합니다. Uno, 드라이버, 서보 전원의 GND는 공통으로 연결하되, 모터 대전류가 신호 GND 경로를 통과하지 않도록 배선합니다. 12 V를 Uno 핀·서보·드라이버 로직 전원에 연결하지 마세요. [드라이버 매뉴얼](https://www.icbanq.com/icdownload/data/ICBShop/Board/MAI-2MT-DC_V30.pdf)을 기준으로 퓨즈와 차단 수단을 선정합니다.

`VOLTAGE 6`은 12 V 전원 기준 약 50% PWM을 뜻합니다. 드라이버 전압 강하와 부하 때문에 실제 모터 단자 전압은 다를 수 있습니다. 이 버전에는 전압·속도 피드백이 없습니다.

## 명령과 안전 시험

USB Serial Monitor는 **115200 baud + Newline**으로 설정합니다.

| 명령 | 동작 |
|---|---|
| `DRIVE 7.0 10` | 명목 +7 V와 왼쪽 10° 조향 |
| `VOLTAGE -3.0` / `MOTOR 20` | 명목 전압 또는 PWM 비율 직접 시험 |
| `STEER -5` / `CENTER` | 조향 / 중앙 |
| `STOP` / `IDLE` | 모터 정지 / 모터 정지와 조향 중앙 |
| `STATUS` / `HELP` | 상태 / 명령 도움말 |
| `TIMEOUT 1500` / `KEEPALIVE` | 명령 감시 시간 설정 / 감시 갱신 |

처음에는 **모터 전원을 끄고 차체를 받쳐 바퀴를 띄운 상태**에서 로직·서보 전원과 USB를 연결합니다. `STATUS`로 `enabled=0`을 확인하고 `STEER 5`, `STEER -5`, `CENTER`로 조향을 확인합니다. `enabled=0`은 코드 상태일 뿐 실제 드라이버 핀 전압의 증거가 아닙니다. **모터 모델·정격·기동/정지 전류와 드라이버 적합성이 확인된 뒤** 전류 제한 가능한 전원에서 `MOTOR 5`, `STOP`처럼 낮은 듀티로 짧게 시험하며 방향·전류·발열을 확인합니다. 기존 `DRIVE 7.0`은 7 V 기동 보정을 적용하므로 최초 시험에 사용하지 않습니다. 방향이 반대면 모든 전원을 끈 뒤 모터 두 선을 바꾸거나 스케치의 `kForwardIn1High`만 바꿉니다.

모터 구동 중 1.5초간 새 명령이나 `KEEPALIVE`가 없으면 Uno가 모터를 정지합니다. 이 감시와 `TIMEOUT`/`KEEPALIVE`는 **Uno 버전의 동작**이며 현재 Nano 버전에는 없습니다. Nano는 TCP 연결이 유지되는 동안 마지막 구동 명령을 유지합니다.

Uno도 리셋 중 ENABLE 상태를 보장하지 않습니다. USB 연결 해제 시 정지와 리셋 중 핀 상태를 같은 시험으로 취급하지 않으며, 리셋·전원 손실의 정지 대책을 확인하기 전에는 지면 주행에 사용하지 않습니다.
